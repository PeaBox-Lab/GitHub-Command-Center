# GitHub Command Center 3.71.0 Release Notes

Version 3.71.0 is built directly from the complete v3.70.0 release. All v3.70 functionality is retained.

## Added
- Ref Compare for left/right commit history, diff statistics and changed-file status.
- Revision Explain for ref verification, object typing, human-readable revision naming and commit metadata.

## Documentation
README.md, CHANGELOG.md, RELEASE_NOTES.md and USER_GUIDE.md are updated as part of the release contract.
