# GitHub Command Center v3.64.0

Version 3.64 begins the product-UX roadmap while continuing debt reduction.

## Home Dashboard
Daily repository state, branch/upstream divergence, warnings, recent commits and direct actions for Changes, History, Sync, Review, GitHub and Release.

## Universal Search
Searches user-facing tools plus local branches, tags and commit messages. Ctrl+K/command discovery remains available; this provides a simpler search-oriented path.

## Repository Insights
Read-only repository storage, contributor, branch recency and churn evidence using existing Git plumbing.

## Automation Center
Safe preset workflows for Before Commit, Before Push, Repository Health and Maintenance. Presets use argument arrays and JobService, not arbitrary shell execution.

## Debt reduction
Four additional legacy utility classes were retired and aliased to extracted centers. Architecture budgets are lowered again with functionality preserved.
