# Contributing

1. Work from an issue or focused branch.
2. Keep Git command execution in services and use argument arrays.
3. Add tests for parser, safety, recovery, plugin, release, or service changes.
4. Run `python -m unittest discover -s tests -v` and `python -m compileall -q .`.
5. Keep destructive workflows behind preview/confirmation/recovery controls.
6. Update README, CHANGELOG, USER_GUIDE, and RELEASE_NOTES when behavior changes.
