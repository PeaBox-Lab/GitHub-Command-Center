# GitHub Command Center 3.82.0 Release Notes

Workspace usability and documentation release.

## New feature
Workspace Profiles now support filter-as-you-type search and read-only health checks for repository existence, Git validity, and preferred branch availability.

## Documentation
README now provides a complete product overview, requirements, installation options, quick start, navigation, Workspace Profiles help, keyboard shortcuts, safety model, architecture, configuration, troubleshooting, validation, development, documentation index, contribution guidance, security reporting, and licensing status.

## Cumulative compatibility
All v3.71-v3.81 functionality and all architecture, security, readiness, packaging, checksum, manifest, and integrity gates remain retained.

## Historical compatibility
Version 3.72 introduced commit graph filters plus stash diff and conflict previews; these capabilities remain included in v3.82.0.
