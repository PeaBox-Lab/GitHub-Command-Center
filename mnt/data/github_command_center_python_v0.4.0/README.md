# GitHub Command Center v0.4.0

A Python desktop replacement for routine GitHub web and TortoiseGit workflows.

## GitHub account workspace
- Dashboard for repositories, stars, forks, issues, activity, insights, and API allowance
- Repository search, creation, opening, and cloning
- Issue creation
- Optional OS-keyring token storage

## Local Git workspace
- Clone or initialize repositories
- Working-tree status, stage selected/all, unstage, discard, commit, fetch, fast-forward-only pull, and push
- Diff viewer and 100-commit history
- Branch creation, switching, merging, deletion, and merge abort
- Stash save/pop, annotated tags, remotes, conflict list, clean preview, and folder opening

## Visual tools
- Color-coded graph for up to 250 commits across all branches and merges
- Three-pane conflict resolver with ours, editable merged result, and theirs
- Use-ours/use-theirs, save, stage-as-resolved, next-conflict, and abort merge

## New advanced tools in v0.4.0
- Guided cherry-pick with continue and abort
- Safe branch rebase with clean-worktree gate and timestamped backup branch
- Commit revert
- Soft, mixed, and hard reset with confirmation and automatic backup branch
- Repository `.gitignore` editor
- Built-in Python and Node ignore templates

## Run on Windows
Extract the ZIP and double-click `run_windows.bat`. Python 3.10+ and Git must be available on PATH.
