# GitHub Command Center v3.11.0

Version 3.11 continues decimal versioning within major version 3 and focuses on commit consistency, patch-series workflows and hook transparency.

## Commit Template Center
- Local repository commit-message template
- Conventional-commit starter template
- Save under `.git` and configure `commit.template`
- Disable repository template cleanly

## Patch Queue Center
- Add multiple format-patch/mailbox files
- Clean-tree safety gate
- Apply queue with `git am --3way`
- Continue, skip or abort a paused application
- Visible session status

## Hook Audit Center
- Inventory non-sample local Git hooks
- Executable status, size and modification time
- Preview hook contents
- Open a hook file or jump to Hooks Manager

All v0.1-v3.10 features remain included through Command Palette.
